## Minecraft汉语方言翻译资源包
## Minecraft Chinese Varieties Translation Resource Pack

这里是Minecraft汉语方言翻译资源包的仓库，欢迎大家来一起贡献翻译!

This is the repository for the Minecraft Chinese varieties translation resource pack. Everyone is welcome to contribute translations!

本项目目前包含以下方言：

This project currently includes the following Chinese varieties:

yue_cn: 粤语 Cantonese

yue_hk: 香港粤语 Hong Kong Cantonese 

yue_mo: 澳门粤语 Macau Cantonese

nan_cn: 闽南语 Hokkien

nan_tw: 台湾闽南语 Taiwanese Hokkien (Taiwanese)

hak_cn: 客家语 Hakka

hak_tw: 台湾客家语 Taiwanese Hokkien

wuu_cn: 吴语 Wu Chinese

cjy_cn: 晋语 Jinyu Chinese

hsn_cn: 湘语 Xiang Chinese

cnp_cn: 桂北平话 Northern Guangxi Pinghua

csp_cn: 桂南平话 Southern Guangxi Pinghua

czh_cn: 徽語 Huizhou Chinese

gan_cn: 贛語 Gan Chinese

zh_sg: 新加坡简体中文（华语） Singapore Simplified Chinese (Mandarin)

zh_mo: 澳门繁体中文（普通话） Macau Traditional Chinese (Mandarin)

cmn_latn: 汉语拼音 Mandarin Chinese written in Hanyu Pinyin

cmn_bopo: 注音符号 Mandarin Chinese written in Bopomofo
